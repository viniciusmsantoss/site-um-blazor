## 🚀 Exercícios Desenvolvidos

1. **Página Sobre (`/sobre`):** Apresentação pessoal utilizando roteamento `@page`.
2. **Contador (`/contador`):** Contagem de cliques utilizando binding C# e evento `@onclick`.
3. **Alternador de Mensagem (`/mensagem`):** Manipulação de exibição do DOM com estado booleano e condicional `@if`.
4. **Placar Interativo (`/placar`):** Gestão de pontuação com botões de adição, subtração (com trava para não ter valores negativos) e reinicialização.
